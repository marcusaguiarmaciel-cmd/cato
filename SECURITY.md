# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within CATO, please do **NOT** open a public issue.

Instead, please send an email directly to **marcus.aguiarmaciel@gmail.com** with the subject line `[SECURITY] CATO Vulnerability Report`.

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Your proposed mitigation or fix (if available).

We will acknowledge your report within 48 hours and work on a fix promptly.
